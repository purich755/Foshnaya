# Фошная — демо главной страницы

Демо-сайт вьетнамской закусочной «Фошная» (Казань, Профсоюзная, 26). Одна страница, концепция «Четырнадцать метров Вьетнама».

```bash
npm i && npm run dev      # http://localhost:8414
npm run build && npm start  # прод на http://localhost:8415
```

**Живая версия:** https://purich755.github.io/Foshnaya/ — GitHub Pages, собирается workflow `.github/workflows/pages.yml` при каждом пуше в `main` (статический экспорт с `GITHUB_PAGES=true`, basePath `/Foshnaya`).
На Vercel проект деплоится без настроек — обычная сборка Next, без basePath. Страница помечена `noindex`: это демо для показа владельцу.

## Стек

Next.js 15 + TypeScript, CSS Modules + токены в `app/globals.css`, GSAP 3 (ScrollTrigger; Draggable / Inertia / MotionPath подгружаются по требованию), Lenis, сырой WebGL для пара (фолбэк — Canvas 2D), sharp для фото.
Шрифты: Dela Gothic One (свой сабсет латиница + кириллица, 15 КБ — `scripts/subset-fonts.mjs`), Geologica, IBM Plex Mono, Be Vietnam Pro, Caveat (последние два подключаются после `load`).

## Структура

- `app/` — layout (шрифты, метаданные, JSON-LD Restaurant без рейтинга), страница, глобальные стили
- `components/layout` — шапка, мобильная панель, футер, плавный скролл + reveal, прогресс, курсор
- `components/fx` — пар (WebGL), вывески с мерцанием, плитка, бумажные ценники, живой статус
- `components/sections` — 12 секций по брифу + лайтбокс; `isoPlan.ts` — геометрия изометрического плана
- `components/ui` — `Photo` (WebP 640/1280/1920), `HydrateLater` (ленивая гидратация секций ниже первого экрана)
- `data/` — `venue.ts` (адрес, телефон, **часы — константа**), `menu.ts`, `reviews.ts`, `toppings.ts`, `photos.ts` (генерируется), `map.json` (схема района)
- `scripts/fetch-photos.mjs` — скачать и пересобрать фото; `scripts/subset-fonts.mjs` — сабсет Dela
- `tools/` — сбор данных (`ya-dump`, `ya-photos`, `vk-dump`, `build-map`), проверки (`interact` — 31 клик-тест, `tour` — скриншоты по секциям, `overflow`, `lh.sh` — Lighthouse)

Время для проверки статуса подменяется параметром: `/?t=22:45`.

## Что не нашлось и чем заменено

- **VK** отдал только текст постов: фото за логин-стеной. Изображений из VK нет.
- **Яндекс Еда** (фото блюд с подписями) закрыта капчей — не использовалась.
- **Креветки «Том Чьен»**: реального фото нет. Сделана типографическая карточка-ценник без фото.
- **Логотип**: векторного нет. В шапке и футере — типографическая вывеска «ФОШНАЯ» на красной плашке. На стакане в блоке размеров — штамп «ФОШ/НАЯ» по мотивам их печати.
- **Схема района** построена из реальной геометрии OpenStreetMap. Пеший маршрут от «Площади Тукая» — 617 м, около 8 минут (routing.openstreetmap.de).

## Палитра сверена с фото

Свежие кадры зала: стены — рыжая охристая фанера, стойка обшита бледно-голубыми панелями (в 2018-м — мятная плитка), меню — мелом на красной доске. Бирюза стойки (`--tile`) заменила «кинзу» вторым акцентом. Охра чуть ржавее, чем в брифе.

## Проверки

- `npm run build` — без ошибок и предупреждений; TypeScript чистый.
- Скриншоты 1440×900, 1024×768, 390×844: без горизонтального скролла и наложений.
- `node tools/interact.mjs http://localhost:8415/` — 31/31: размеры фо (мышь и клавиатура), миска (клик, перетаскивание, мимо миски, Enter, сброс), JVC (CH±, миниатюры, стрелки, лайтбокс, фокус-ловушка, Esc), FAQ, хот-споты, чеки, якоря, мобильное меню, статус в 13:00 / 22:45 / 08:00, консоль без ошибок.
- `prefers-reduced-motion`: пар статичный, мерцание и шум JVC выключены, пин-сцена раскладывается статично, Lenis выключен.
- Dev-режим: без предупреждений гидратации.
- Lighthouse mobile (localhost, симуляция): Performance 82, Accessibility 100, Best Practices 100; CLS 0,002, FCP 1,7 с, TBT ~400 мс, LCP 3,2 с. С реальным троттлингом DevTools LCP — 2,0 с. Цель Performance ≥ 85 стабильно не достигнута: остаток — первая раскладка длинной страницы и выполнение JS (Next + React + GSAP) до первой отрисовки. SEO 63 только из-за намеренного `noindex`.

## Уточнить у клиента

1. Часы: 12:00–23:00 ежедневно — так на Картах и в посте VK. Одинаково ли в выходные?
2. Меню и цены: на сайте — меню доставки. На доске в зале другие позиции и цены (фо 300/390/470, бань бао 230, спринг-ролл 160, нэм 100, сок 150 — по фото разных лет). Какие актуальны?
3. Цены на нэмы и бань бао, наличие бань бао.
4. Добавки на стойке: список взят из Афиши 2018. Что стоит сейчас? Вьетнамские подписи к добавкам (hành tím, ớt, chanh, gừng, bạc hà, giấm, tương ớt, sa tế) стоит проверить носителю языка.
5. Хозяйка: на фото в блоке «Хозяйка стойки» — женщина с бань бао у доски меню (фото с Карт). Она ли сейчас за стойкой, можно ли использовать фото, как её зовут (имя на сайте не указано).
6. Телевизор JVC: виден на фото 2018 и на кадре с хозяйкой. Висит ли сейчас и крутят ли клипы.
7. Логотип: есть ли вектор печати «ФОШНАЯ».
8. В шапке VK — «Гастро открытие года 2018», «Стрит фуд года 2019». На сайт не выносили (бриф запрещает награды); если подтвердят источник — можно добавить.
9. Точка на Декабристов, 8г — филиал или другая компания.
